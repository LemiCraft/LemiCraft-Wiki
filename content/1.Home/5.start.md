# Первый запуск и настройка

Вы установили лаунчер и моды — теперь пора запустить игру и настроить её для комфортной игры на LemiCraft

## Запуск игры

### 1. Выберите правильный профиль

В Legacy Launcher:

1. Убедитесь, что выбрана версия **1.21.10**
2. Убедитесь, что выбран загрузчик **Fabric** (если вы используете моды)
3. Проверьте, что вы вошли в аккаунт (Ely.by или Microsoft)

### 2. Нажмите "Играть"

Первый запуск может занять несколько минут — игра загружает все ресурсы и инициализирует моды

::note
Если игра долго загружается, это нормально для первого запуска. Последующие запуски будут быстрее
::

## Настройка модов

### Plasmo Voice

Plasmo Voice добавляет пространственный голосовой чат в игру — вы можете общаться голосом с игроками рядом

**Первая настройка:**

1. После входа на сервер нажмите **V** (стандартная клавиша)
2. Выберите микрофон из списка устройств
3. Настройте громкость микрофона ползунком
4. Проверьте громкость других игроков

**Полезные команды:**

- `/vm` — записать голосовое сообщение
- `/vrc` — переподключиться к голосовому чату

**Настройка клавиш:**

- Откройте настройки Minecraft
- Перейдите в раздел "Управление"
- Найдите раздел "Plasmo Voice"
- Настройте клавиши под себя:
  - **Push to Talk** — говорить по нажатию (рекомендуется)
  - **Toggle Voice** — включить/выключить микрофон
  - **Mute** — быстро заглушить себя

::tip
**Совет**: Используйте Push to Talk (например, клавишу **C**), чтобы не передавать фоновые шумы
::

### Emotecraft

Emotecraft позволяет использовать эмоции и анимации персонажа

**Как использовать:**

1. Нажмите **B** для открытия меню эмоций (или настройте клавишу в управлении)
2. Выберите эмоцию из списка
3. Ваш персонаж воспроизведёт анимацию

**Настройка:**

- Нажмите **B** для открытия меню, внизу будет кнопка открытия полного меню
- Настройте клавиши для быстрого доступа к эмоциям

### Sodium & Iris

Эти моды значительно улучшают производительность и добавляют поддержку шейдеров

**Настройка графики через Sodium:**

1. В главном меню нажмите "Настройки"
2. Нажмите "Графика"
3. В правом верхнем углу найдите кнопку с логотипом Sodium
4. Рекомендуемые настройки:
   - **Качество графики**: Fancy (для красоты) или Fast (для производительности)
   - **Дальность прорисовки**: 8-16 чанков (баланс)
   - **VSync**: Включено (убирает разрывы изображения)

**Расширенные настройки Sodium:**

- **Quality** → Mipmap Levels: 4 (для чёткости текстур)
- **Performance** → Chunk Builder: Threaded (лучшая производительность)
- **Performance** → Use Block Face Culling: Включено

::warning
Если у вас слабый ПК, установите дальность прорисовки 6-10 чанков и отключите сглаживание
::

## Настройка шейдеров

### Установка шейдер-паков

1. **Скачайте шейдер-пак**:
   - [BSL Shaders](https://www.curseforge.com/minecraft/shaders/bsl-shaders) — сбалансированный, красивый
   - [Complementary Shaders](https://www.curseforge.com/minecraft/shaders/complementary-shaders) — реалистичный
   - [Sildur's Vibrant Shaders](https://sildurs-shaders.github.io/) — яркий и производительный

2. **Поместите файл в папку shaderpacks**:
   - Откройте папку `.minecraft`
   - Создайте папку `shaderpacks`, если её нет
   - Скопируйте скачанный `.zip` файл (не распаковывать!)

3. **Включите шейдер в игре**:
   - Откройте "Настройки" → "Графика"
   - Нажмите "Shader Packs..." (кнопка Iris)
   - Выберите нужный шейдер из списка
   - Нажмите "Apply"

::warning
**Системные требования для шейдеров:**
- Минимум 4 ГБ RAM выделено для Minecraft
- Хорошая видеокарта
::

### Рекомендуемые настройки шейдеров

Для слабых ПК:
- **Sildur's Enhanced Default** — минимальная нагрузка
- Дальность прорисовки: 8 чанков
- Отключите тени или поставьте Low

Для средних ПК:
- **BSL Shaders** на Medium настройках
- Дальность прорисовки: 12 чанков
- Тени на Medium

Для мощных ПК:
- **Complementary Shaders** на High/Ultra
- Дальность прорисовки: 16+ чанков
- Все эффекты включены

## Установка ресурс-паков

Ресурс-паки изменяют текстуры, звуки и внешний вид игры

### Установка

1. **Скачайте ресурс-пак**:
   - [Faithful](https://faithfulpack.net/) — HD версия стандартных текстур
   - [Stay True](https://www.curseforge.com/minecraft/texture-packs/stay-true) — улучшенные ванильные текстуры
   - [Fresh Animations](https://modrinth.com/resourcepack/fresh-animations) — добавляет красивые анимации мобам (требует CEM)

2. **Поместите в папку resourcepacks**:
   - Откройте папку `.minecraft`
   - Создайте папку `resourcepacks`, если её нет
   - Скопируйте скачанный `.zip` файл

3. **Активируйте в игре**:
   - Откройте "Настройки" → "Ресурс-паки"
   - Найдите пак в левом списке
   - Нажмите стрелку вправо для активации
   - Нажмите "Готово"

::tip
**Совет**: Можно использовать несколько ресурс-паков одновременно. Порядок имеет значение — верхние паки переопределяют нижние
::

## Настройка производительности

### Выделение памяти (RAM)

Для комфортной игры с модами рекомендуется выделить больше RAM:

1. Откройте Legacy Launcher
2. Перейдите в "Настройки"
3. Найдите раздел "Java"
4. Установите значение RAM:
   - **Минимум**: 2048 МБ (2 ГБ)
   - **Рекомендуется**: 4096 МБ (4 ГБ)
   - **С шейдерами**: 6144-8192 МБ (6-8 ГБ)

::warning
Не выделяйте всю доступную RAM! Оставьте 2-4 ГБ для системы
::

## Общие настройки Minecraft

### Рекомендуемые настройки графики

- **Графика**: Fancy
- **Плавное освещение**: Максимум
- **Дальность прорисовки**: 12-16 чанков
- **VSync**: Включено
- **Частицы**: Все или Уменьшено
- **Анимация**: Всё включено

## Проверка работоспособности

После настройки проверьте:

✅ **Моды загружаются**: откройте Mod Menu и проверьте список  
✅ **Шейдеры работают**: небо и освещение изменились  
✅ **Голосовой чат**: вы видите иконку микрофона в углу экрана  
✅ **FPS стабильный**: 60+ FPS без просадок  

## Частые проблемы

### Игра вылетает при запуске

**Решение:**
1. Проверьте, что все моды для версии 1.21.10 и Fabric
2. Убедитесь, что установлен Fabric API
3. Увеличьте выделенную RAM
4. Удалите последний установленный мод

### Низкий FPS

**Решение:**
1. Уменьшите дальность прорисовки
2. Отключите шейдеры
3. Установите "Графика: Fast"
4. Выделите больше RAM
5. Установите дополнительные моды оптимизации

### Не работает Plasmo Voice

**Решение:**
1. Проверьте, что мод установлен на клиенте
2. Используйте команду `/vrc` для переподключения
3. Проверьте настройки микрофона в системе
4. Убедитесь, что микрофон не заблокирован антивирусом

### Шейдеры не включаются

**Решение:**
1. Убедитесь, что установлен Iris Shaders
2. Проверьте, что шейдер-пак в папке `shaderpacks`
3. Файл должен быть `.zip`, не распакованный
4. Попробуйте другой шейдер-пак
