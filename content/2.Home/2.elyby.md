# Регистрация на Ely.by

Если у вас нет лицензионного аккаунта Minecraft, вы можете использовать сервис **Ely.by** — бесплатную альтернативу для игры на проекте

## Что такое Ely.by?

Ely.by — это бесплатный сервис скинов и авторизации для Minecraft серверов, альтернатива лицензионной системы

## Шаги регистрации

### 1. Перейдите на сайт

Откройте [ely.by](https://ely.by) в браузере

### 2. Нажмите "Зарегистрировать аккаунт"

Найдите и нажмите на кнопку регистрации

### 3. Заполните форму

Вам потребуется указать:
- **Email** — действующая почта для подтверждения
- **Никнейм** — ваше игровое имя (можно будет изменить позже)
- **Пароль** — придумайте надёжный пароль

### 4. Подтвердите email

После регистрации на вашу почту придёт письмо с ссылкой для подтверждения. Перейдите по ней

### 5. Готово!

Теперь вы можете использовать этот аккаунт для входа через Legacy Launcher

## Важные замечания

::warning
Запомните свой email и пароль — они понадобятся для входа в лаунчер!
::

::note
Никнейм можно изменить в личном кабинете на сайте Ely.by
::
