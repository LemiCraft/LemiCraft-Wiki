# Установка лаунчера

## LemiCraft Launcher

У нас есть собственный официальный лаунчер с автоматической установкой модпака, авторизацией через Microsoft и Ely.by, а также новостями сервера прямо внутри приложения

::note
**Только для Windows.** Поддержка других платформ появится позже — пока используйте Legacy Launcher
::

::lemi-launcher-download
::


**Инструкция:**

1. **Скачайте установщик** — файл `LemiCraft_Installer.exe`
2. **Запустите файл** и следуйте инструкциям установщика
3. **Запустите лаунчер** — найдите ярлык на рабочем столе или в меню Пуск
4. **Войдите** через Microsoft или Ely.by
5. Нажмите **«Играть»** — моды установятся автоматически

---

## Установка по платформам

### Windows

**Системные требования:**
- Windows 7 или новее (64-bit)
- 2 ГБ свободного места на диске
- Java установится автоматически

**Инструкция:**

1. **Скачайте установщик** — нажмите кнопку "Windows" выше
2. **Запустите файл** — дважды кликните на скачанный `.exe` файл
3. **Выберите папку** — рекомендуется оставить путь по умолчанию (`C:\Program Files\Legacy Launcher`)
4. **Дождитесь установки** — процесс займёт 1-2 минуты
5. **Запустите лаунчер** — найдите ярлык на рабочем столе или в меню Пуск

::note
При первом запуске Windows может запросить разрешение администратора — это нормально
::

### macOS

**Системные требования:**
- macOS 10.12 Sierra или новее
- Процессор Intel (x64) или Apple Silicon через Rosetta
- 2 ГБ свободного места

**Инструкция:**

1. **Скачайте образ** — нажмите кнопку "macOS" выше
2. **Откройте `.dmg` файл** — дважды кликните на скачанный файл
3. **Перетащите в Applications** — перенесите иконку Legacy Launcher в папку Applications
4. **Первый запуск**:
   - Откройте приложение из папки Applications
   - Если появится предупреждение безопасности:
     - Откройте `Системные настройки → Защита и безопасность`
     - Нажмите "Разрешить" рядом с Legacy Launcher
     - Запустите приложение снова

::warning
**Распространённые ошибки на macOS:** Если система пишет, что приложение повреждено или от неизвестного разработчика, ознакомьтесь с [официальной инструкцией Apple](https://support.apple.com/guide/mac-help/if-you-cant-open-an-app-mchlp1519/mac)
::

### Linux

**Для Ubuntu / Debian:**

1. **Скачайте `.deb` пакет** — нажмите кнопку "Ubuntu/Debian" выше
2. **Установите пакет**:
   ```bash
   sudo dpkg -i LegacyLauncher*.deb
   sudo apt-get install -f  # Установит зависимости
   ```
3. **Запустите** — найдите Legacy Launcher в меню приложений

**Для других дистрибутивов (универсальный способ):**

1. **Установите Java**:
   ### Arch Linux
   ```bash
   sudo pacman -S jre-openjdk
   ```
   ### Fedora
   ```
   sudo dnf install java-17-openjdk
   ```
   ### OpenSUSE
   ```
   sudo zypper install java-17-openjdk
   ```

2. **Скачайте JAR файл** — в разделе "Дополнительные платформы" выберите "Универсальный JAR"

3. **Запустите лаунчер**:
   ```bash
   java -jar LegacyLauncher.jar
   ```

4. **Создайте ярлык** (опционально):
   ```bash
   cat > ~/.local/share/applications/legacylauncher.desktop << EOF
   [Desktop Entry]
   Type=Application
   Name=Legacy Launcher
   Exec=java -jar /path/to/LegacyLauncher.jar
   Icon=/path/to/icon.png
   Terminal=false
   Categories=Game;
   EOF
   ```

**Для Flatpak:**

Откройте терминал и выполните:
```bash
flatpak install flathub ru.legacylauncher.LegacyLauncher
flatpak run ru.legacylauncher.LegacyLauncher
```

::warning
**Важно:** Версия из Flathub требует **лицензионный аккаунт Minecraft**. Для Ely.by используйте обычную версию
::

## Первый запуск и настройка

### Шаг 1: Выбор типа аккаунта

При первом запуске лаунчер предложит выбрать тип аккаунта:

- **🟢 Ely.by** — для игры без лицензии (рекомендуется для LemiCraft)
- **🔵 Microsoft** — для владельцев лицензионной версии через Microsoft

### Шаг 2: Вход через Ely.by

Если вы используете Ely.by:

1. Нажмите на выпадающий список типов аккаунтов (сверху)
2. Выберите **"Ely.by"**
3. Нажмите "Авторизоваться на Ely.by"
4. Продолжите авторизацию в браузере
5. Вернитесь в лаунчер

::callout
После успешного входа вы увидите свой никнейм в верхней части лаунчера
::

### Шаг 3: Выбор версии Minecraft

Для игры на LemiCraft:

1. В главном окне лаунчера найдите выпадающий список версий
2. Выберите версию **1.21.10**
3. Если планируете использовать моды, выберите **"Fabric 1.21.10"**

::note
**Для LemiCraft рекомендуется:** версия **1.21.10 с Fabric** — под неё у нас есть готовая сборка
::

## Дополнительные настройки

### Смена скина

Для смены скина при использовании Ely.by:

1. Перейдите на [ely.by](https://ely.by)
2. Войдите в свой аккаунт
3. Откройте раздел "Профиль"
4. Выберите скин из списка или загрузите свой
5. Перезапустите игру — скин применится автоматически
