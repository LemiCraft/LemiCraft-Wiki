# Установка модов

Для комфортной игры на LemiCraft рекомендуется установить несколько модов, которые улучшат производительность и добавят полезные функции

## Рекомендуемые моды

### Обязательные моды

::card-group
  :::card
  ---
  icon: i-lucide-zap
  title: Fabric API
  ---
  Библиотека, необходимая для работы почти всех модов на Fabric
  :::

  :::card
  ---
  icon: i-lucide-gauge
  title: Sodium
  ---
  Значительно улучшает производительность игры (замена Optifine)
  :::

  :::card
  ---
  icon: i-lucide-sparkles
  title: Iris Shaders
  ---
  Позволяет использовать шейдеры вместе с Sodium
  :::
::

### Полезные дополнительные моды

- **ModMenu** — удобное меню для управления модами
- **Lithium** — оптимизация физики и игровой логики
- **Plasmo Voice** — голосовой чат в игре
- **Roughly Enough Items (REI)** — показывает рецепты крафта
- **Xaero's Minimap** — мини-карта

## Как установить Fabric?

Если вы используете не официальный Minecraft лаунчер - вы можете установить Fabric версию прямо из списка всех версий, но мы рекомендуем установить вручную

Для этого нужно:

1. Скачайте Fabric Installer с [fabricmc.net](https://fabricmc.net)
2. Запустите установщик и выберите версию **1.21.10**
3. Нажмите "Install"

### Где найти и скачать моды?

Моды можно найти просто используя поисковик в браузере, но мы рекомендуем скачивать с проверенных ресурсов:

- [Modrinth](https://modrinth.com/discover/mods) — рекомендуется
- [CurseForge](https://www.curseforge.com/minecraft)

::warning
Убедитесь, что скачиваете моды для версии **1.21.10** и загрузчика **Fabric**!
::

### Как установить мод?

1. Откройте папку `.minecraft`:
   - **Windows**: `%appdata%/.minecraft`
   - **macOS**: `~/Library/Application Support/minecraft`
   - **Linux**: `~/.minecraft`

2. Создайте папку `mods`, если её нет
3. Скопируйте скачанные `.jar` файлы модов в папку `mods`
4. Запустите игру через профиль с Fabric

## Готовая сборка модов

На сайте LemiCraft есть **Сборщик модпака** — удобный способ выбрать нужные моды, ресурспаки и шейдеры и скачать их одним архивом.

::tip
**[Открыть Сборщик модпака →](https://lemicraft.ru/mods)**
::

Можно собрать свой набор вручную или скачать готовую сборку:

- **Минимальная** — самое необходимое для комфортной игры
- **Рекомендуемая** — полный набор модов от администрации

::note
Распакуйте архив и скопируйте содержимое в `.minecraft`
::

## Проверка установки

После установки запустите игру и:

1. Откройте главное меню
2. Нажмите "Mods" (если установлен ModMenu)
3. Убедитесь, что все моды отображаются в списке

## Проблемы при установке

### Игра не запускается

- Проверьте, что все моды для версии 1.21.10
- Убедитесь, что установлен Fabric API
- Удалите моды по одному, чтобы найти проблемный
- Проверьте логи запуска

### Низкая производительность

- Установите Sodium и Lithium
- Уменьшите настройки графики
- Выделите больше RAM в лаунчере
