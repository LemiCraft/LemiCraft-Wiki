# Установка ресурс-паков

Ресурс-паки позволяют изменить внешний вид Minecraft: текстуры блоков, предметов, звуки и многое другое

## Что такое ресурс-пак?

Ресурс-пак (Resource Pack) — это набор файлов, который заменяет стандартные текстуры, модели, звуки и другие игровые ресурсы на кастомные

## Рекомендуемые ресурс-паки

### Faithful

**HD версия стандартных текстур**

- Сохраняет ванильный стиль
- Увеличивает разрешение текстур (32x32 вместо 16x16)
- Подходит для любых сборок

**Скачать:** [faithfulpack.net](https://faithfulpack.net/)

### BACAP Language Pack

**Перевод игровых достижений**

- Добавляет перевод дополнитеных достижений сервера
- Сохраняет атмосферу ванильного Minecraft
- Доступны многие языки

**Скачать:** [Modrinth](https://modrinth.com/resourcepack/bacap-language-pack)

### Fresh Animations

**Улучшенные анимации мобов**

- Добавляет реалистичные анимации для мобов
- Требует мод **Entity Model Features** или **CEM**
- Значительно улучшает внешний вид существ

**Скачать:** [Modrinth](https://modrinth.com/resourcepack/fresh-animations)

## Как установить ресурс-пак

### Способ 1: Через игру (рекомендуется)

1. **Скачайте ресурс-пак**
   - Файл должен быть в формате `.zip`
   - Не распаковывайте архив!

2. **Откройте Minecraft**
   - Запустите игру через лаунчер

3. **Перейдите в настройки**
   - Нажмите "Настройки" → "Ресурс-паки"

4. **Откройте папку с паками**
   - Нажмите кнопку "Open Pack Folder" внизу слева

5. **Скопируйте файл**
   - Перетащите скачанный `.zip` файл в открывшуюся папку

6. **Активируйте пак**
   - Вернитесь в игру (окно с ресурс-паками должно обновиться)
   - Найдите ваш пак в левом списке "Доступные"
   - Наведите на него и нажмите стрелку вправо →
   - Пак переместится в правый список "Выбранные"

7. **Примените изменения**
   - Нажмите "Готово" (Done)
   - Игра перезагрузит ресурсы (займёт несколько секунд)

::note
Готово! Ресурс-пак активирован и работает
::

### Способ 2: Вручную через папку

1. **Найдите папку `.minecraft`**

   **Windows:**
   ```
   %appdata%\.minecraft
   ```
   
   **macOS:**
   ```
   ~/Library/Application Support/minecraft
   ```
   
   **Linux:**
   ```
   ~/.minecraft
   ```

2. **Откройте папку `resourcepacks`**
   - Если её нет — создайте

3. **Скопируйте файл**
   - Поместите скачанный `.zip` файл в эту папку

4. **Активируйте в игре**
   - Запустите Minecraft
   - Перейдите в "Настройки" → "Ресурс-паки"
   - Выберите ваш пак из списка

## Использование нескольких паков

Minecraft позволяет использовать несколько ресурс-паков одновременно

### Как это работает

- Паки применяются сверху вниз
- Верхние паки **переопределяют** нижние
- Если верхний пак не содержит какую-то текстуру, используется версия из нижнего пака

### Пример комбинации

```
┌─────────────────────────┐
│  Fresh Animations       │ ← Анимации мобов
├─────────────────────────┤
│  Vanilla Tweaks         │ ← Улучшения интерфейса
├─────────────────────────┤
│  Stay True              │ ← Основные текстуры
└─────────────────────────┘
```

### Как изменить порядок

В меню ресурс-паков:
1. Наведите курсор на пак в правом списке
2. Используйте стрелки ↑ и ↓ для изменения порядка
3. Верхние паки имеют приоритет

## Решение проблем

### Пак не появляется в списке

**Возможные причины:**
- Файл не в формате `.zip`
- Пак распакован (должен быть архивом)
- Пак для другой версии Minecraft
- Повреждённый файл

**Решение:**
1. Убедитесь, что файл `.zip`
2. Проверьте совместимость версий
3. Скачайте файл заново

### Текстуры отображаются неправильно

**Возможные причины:**
- Пак для другой версии игры
- Конфликт с другими паками
- Неполный пак

**Решение:**
1. Проверьте версию пака (должна быть 1.21.10)
2. Попробуйте использовать пак один, без других
3. Переустановите пак

### Игра тормозит после установки

**Возможные причины:**
- HD текстуры требуют больше ресурсов
- Слишком много паков активировано

**Решение:**
1. Выделите больше RAM в лаунчере (минимум 4 ГБ)
2. Используйте меньше паков одновременно
3. Выберите паки с меньшим разрешением текстур

### Некоторые текстуры розовые/чёрные

**Причина:** Пак неполный или повреждён

**Решение:**
1. Скачайте пак заново
2. Проверьте, что скачали правильную версию
3. Сообщите автору пака о проблеме

## Создание собственных паков

Хотите создать свой ресурс-пак?

### Полезные инструменты

- **Vanilla Tweaks** — конструктор кастомных паков: [vanillatweaks.net](https://vanillatweaks.net/)
- **Paint.NET** / **GIMP** — для редактирования текстур
- **Blockbench** — для создания 3D моделей

### Структура ресурс-пака

```
resourcepack.zip
├── pack.mcmeta          # Информация о паке
├── pack.png             # Иконка пака (опционально)
└── assets/
    └── minecraft/
        ├── textures/    # Текстуры
        ├── sounds/      # Звуки
        ├── models/      # Модели
        └── lang/        # Переводы
```
