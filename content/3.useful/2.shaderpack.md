# Что такое шейдеры?

Шейдеры (Shaders) — это специальные программы, которые изменяют способ отрисовки графики в игре, добавляя:

::tip
Быстрый способ — выбрать шейдер в **[Сборщике модпака](https://lemicraft.ru/mods)** на сайте LemiCraft и скачать вместе с нужными модами
::
- Реалистичное освещение и тени
- Отражения в воде
- Объёмные облака и туман
- Размытие в движении
- Улучшенные эффекты воды и стекла

## Где найти шейдеры?

В интернете полно сайтов с различными паками, вот некоторые популярные из них:

- [Modrinth](https://modrinth.com/discover/shaders)
- [CurseForge](https://www.curseforge.com/minecraft/search?class=shader)
- [Minecraft Inside](https://minecraft-inside.ru/shaders)

## Требования

### Необходимые моды

Для работы шейдеров нужен мод **Iris Shaders**:

::warning
**Важно!** Iris работает только вместе с **Sodium**. Убедитесь, что оба мода установлены
::

Как установить Iris:
1. Скачайте [Iris Shaders](https://modrinth.com/mod/iris) для версии 1.21.10 (Fabric)
2. Поместите файл `.jar` в папку `mods`
3. Запустите игру

### Системные требования

Минимальные:
- **CPU:** Intel Core i5 / AMD Ryzen 5
- **RAM:** 4 ГБ (выделено для Minecraft)
- **GPU:** Nvidia GTX 1050 / AMD RX 560

Рекомендуемые:
- **CPU:** Intel Core i7 / AMD Ryzen 7
- **RAM:** 6-8 ГБ (выделено для Minecraft)
- **GPU:** Nvidia GTX 1660 / AMD RX 5600

## Рекомендуемые шейдеры

### BSL Shaders

**Сбалансированный и красивый**

- Хорошая производительность
- Реалистичное освещение
- Красивые закаты и рассветы
- Подходит для большинства ПК

**Скачать:** [CurseForge](https://www.curseforge.com/minecraft/shaders/bsl-shaders) или [Modrinth](https://modrinth.com/shader/bsl-shaders)

### Complementary Shaders

**Максимально реалистичный**

- Очень детализированные эффекты
- Объёмные облака
- Лучшие отражения
- Требует мощный ПК

**Скачать:** [CurseForge](https://www.curseforge.com/minecraft/shaders/complementary-shaders) или [Modrinth](https://modrinth.com/shader/complementary-shaders)

### Sildur's Vibrant Shaders

**Яркий и производительный**

- Несколько версий (Lite, Medium, High, Extreme)
- Отличная оптимизация
- Яркие, насыщенные цвета
- Хорош для слабых ПК

**Скачать:** [Sildur's Website](https://sildurs-shaders.github.io/) или [CurseForge](https://www.curseforge.com/minecraft/shaders/sildurs-vibrant-shaders)

### Для слабых ПК

- **Sildur's Enhanced Default** — минимальная нагрузка
- **Vanilla Plus Shaders** — почти как ваниль
- **Chocapic13 Low** — простой и красивый

### Шаг 1: Скачайте шейдер-пак

1. Перейдите на сайт выбранного шейдера
2. Скачайте файл `.zip` для версии 1.21.x
3. **НЕ распаковывайте архив!**

### Шаг 2: Поместите в папку shaderpacks

**Способ 1: Через игру (рекомендуется)**

1. Запустите Minecraft
2. Откройте "Настройки" → "Графика"
3. Нажмите кнопку "Shader Packs..." (от Iris)
4. Внизу слева нажмите "Open Shader Pack Folder"
5. Скопируйте `.zip` файл в открывшуюся папку

**Способ 2: Вручную**

1. Откройте папку `.minecraft`:
   - **Windows:** `%appdata%\.minecraft`
   - **macOS:** `~/Library/Application Support/minecraft`
   - **Linux:** `~/.minecraft`

2. Создайте папку `shaderpacks`, если её нет

3. Скопируйте `.zip` файл в эту папку

### Шаг 3: Активируйте шейдер

1. В игре откройте "Настройки" → "Графика"
2. Нажмите "Shader Packs..."
3. В списке появится ваш шейдер-пак
4. Кликните на него один раз
5. Нажмите "Apply"
6. Дождитесь загрузки (может занять 10-30 секунд)

::callout{type="success"}
Готово! Шейдеры активированы
::

## Настройка шейдеров

### Базовые настройки

После активации шейдера:

1. Нажмите на название шейдера в списке
2. Нажмите кнопку "Shader Pack Settings"
3. Здесь доступны настройки:

**Основные параметры:**
- **Shadows** — качество теней (Low/Medium/High)
- **Clouds** — тип облаков (Vanilla/Flat/Volumetric)
- **Water** — качество воды
- **Sky** — качество неба

## Решение проблем

### Шейдеры не включаются

**Проблема:** При выборе шейдера ничего не происходит

**Решение:**
1. Убедитесь, что установлен **Iris Shaders**
2. Проверьте, что файл `.zip`, а не распакованный
3. Скачайте шейдер заново
4. Проверьте совместимость версий

### Чёрный экран при загрузке

**Проблема:** После выбора шейдера экран становится чёрным

**Решение:**
1. Нажмите **K** (клавиша переключения шейдеров)
2. Откройте настройки шейдера и снизьте качество
3. Попробуйте другой шейдер
4. Обновите драйвера видеокарты

### Очень низкий FPS

**Проблема:** Игра тормозит с шейдерами

**Решение:**
1. Выберите более лёгкий шейдер
2. Снизьте настройки шейдера
3. Уменьшите дальность прорисовки
4. Выделите больше RAM (6-8 ГБ)
5. Установите дополнительные моды оптимизации

### Странные артефакты/мерцания

**Проблема:** Видны странные полосы, мерцания, неправильные тени

**Решение:**
1. Обновите драйвера видеокарты
2. Отключите VSync в настройках шейдера
3. Попробуйте другую версию шейдера
4. Снизьте качество теней

### Вода выглядит странно

**Проблема:** Вода полностью прозрачная или слишком тёмная

**Решение:**
1. Откройте настройки шейдера
2. Найдите раздел "Water"
3. Попробуйте разные настройки:
   - Water Type: Vanilla / Clear / Realistic
   - Water Texture: ON
4. Перезагрузите шейдер (отключите и включите снова)

## Полезные клавиши

При использовании Iris Shaders:

- **K** — быстрое включение/выключение шейдеров
- **O** — открыть настройки Iris (Shader Options)
- **F3** — показать FPS и информацию

## Комбинирование с ресурс-паками

Шейдеры отлично работают с ресурс-паками!

**Рекомендуемые комбинации:**

```
BSL Shaders + Stay True
→ Реалистичное освещение + улучшенные текстуры

Complementary + Faithful
→ Максимальный реализм + HD текстуры

Sildur's Vibrant + Vanilla Tweaks
→ Яркая картинка + небольшие улучшения
```

## Создание скриншотов

С шейдерами скриншоты получаются особенно красивыми!

**Советы для скриншотов:**
1. Включите лучшие настройки шейдера
2. Дождитесь красивого времени суток (закат/рассвет)
3. Используйте **F1** для скрытия интерфейса
4. Нажмите **F2** для создания скриншота
5. Скриншоты сохраняются в `.minecraft/screenshots`
