# Гайд по Brewery

Плагин **Brewery** добавляет в игру возможность варить различные алкогольные напитки со своими уникальными эффектами

## Что такое Brewery?

Brewery — это плагин, который позволяет игрокам создавать алкогольные напитки с реалистичной системой опьянения и различными эффектами

### Основные возможности

- Варка различных напитков (пиво, вино, ром, абсент и др.)
- Система опьянения с визуальными эффектами
- Выдержка напитков для улучшения качества
- Уникальные эффекты для каждого напитка

## Процесс создания напитка

Создание напитка состоит из нескольких этапов:

### 1. Варка (Brewing)

**Что нужно:**
- Котёл с водой над огнём
- Ингредиенты по рецепту
- Часы (для отслеживания времени варки)

**Как варить:**

1. Поставьте котёл над источником огня (костёр, огонь, лава)
2. Наполните котёл водой (ПКМ с ведром воды)
3. Добавьте ингредиенты (ПКМ по котлу с предметом в руке)
4. Варите нужное время
5. Наберите напиток в бутылки (ПКМ по котлу с пустыми бутылками)

::callout{type="info"}
**Важно:** Часы показывают, сколько минут варится содержимое котла. Следите за временем варки!
::

### 2. Дистилляция (Distilling)

**Что нужно:**
- Варочная стойка
- Светопыль в качестве фильтра

**Как дистиллировать:**

1. Поместите напиток в варочную стойку
2. Добавьте светопыль в верхний слот
3. Дождитесь завершения процесса
4. Повторите нужное количество раз

::note
Не все напитки требуют дистилляции. Проверяйте рецепт!
::

### 3. Выдержка (Aging)

**Что нужно:**
- Бочка (из досок и табличек)
- Время

**Как построить бочку:**

**Маленькая бочка (9 слотов):**
```
Вид сверху:
┌─────┐
│ Д Д │
│ Д Д │
└─────┘

Д = Деревянные ступени
Таблички на двух противоположных сторонах нижнего блока
```

**Большая бочка (27 слотов):**
```
Вид сверху:
┌─────────┐
│ Д Д Д Д │
│ Д     Д │
│ Д     Д │
│ Д Д Д Д │
└─────────┘

Д = Деревянные ступени (2 слоя)
Таблички на четырёх сторонах нижнего слоя
```

**Как выдерживать:**

1. ПКМ по табличке бочки с бутылкой в руке
2. Положите напиток в бочку
3. Подождите нужное время
4. Заберите выдержанный напиток

::callout{type="warning"}
Внимание! Тип древесины влияет на качество напитка:
- **Дуб** — стандарт (1x скорость)
- **Берёза, Тёмный дуб** — быстрее (1.5x)
- **Другие типы** — медленнее или не подходят
::

## Рецепты напитков

### Пиво (Beer)

**Ингредиенты:**
- 3x Пшеница

**Процесс:**
1. Варка: 8 минут
2. Дистилляция: не требуется
3. Выдержка: 2+ года (игровых дней)
4. Дополнительно: можно добавить 1 хмель для горечи

**Эффекты:**
- Лёгкое опьянение
- Небольшое восстановление голода

### Пшеничное пиво (Wheat Beer)

**Ингредиенты:**
- 6x Пшеница

**Процесс:**
1. Варка: 8 минут
2. Дистилляция: не требуется
3. Выдержка: 2 года
4. Качество улучшается до 3 лет

**Эффекты:**
- Среднее опьянение
- Восстановление сытости

### Вино (Wine)

**Ингредиенты:**
- 5x Ягоды сладкие

**Процесс:**
1. Варка: 5 минут
2. Дистилляция: не требуется
3. Выдержка: 20+ лет
4. Лучшее качество: 30 лет

**Эффекты:**
- Среднее опьянение
- Эффект регенерации (хорошая выдержка)

### Ром (Rum)

**Ингредиенты:**
- 14x Сахарный тростник

**Процесс:**
1. Варка: 5 минут
2. Дистилляция: 2 раза
3. Выдержка: 14 лет в дубовой бочке
4. Качество улучшается до 18 лет

**Эффекты:**
- Сильное опьянение
- Повышение скорости

### Водка (Vodka)

**Ингредиенты:**
- 10x Картофель

**Процесс:**
1. Варка: 15 минут
2. Дистилляция: 3 раза
3. Выдержка: не требуется (или короткая)

**Эффекты:**
- Очень сильное опьянение
- Эффект слабости

### Абсент (Absinth)

**Ингредиенты:**
- 15x Трава

**Процесс:**
1. Варка: 3 минуты
2. Дистилляция: 6 раз
3. Выдержка: не требуется
4. Цвет: зелёный

**Эффекты:**
- Экстремальное опьянение
- Эффект отравления
- Галлюцинации

::callout{type="danger"}
**Опасно!** Абсент — самый крепкий напиток. Употребляйте с осторожностью!
::

### Эль (Ale)

**Ингредиенты:**
- 3x Пшеница
- 1x Хмель (необязательно)

**Процесс:**
1. Варка: 7 минут
2. Дистилляция: не требуется
3. Выдержка: 1-3 года

**Эффекты:**
- Лёгкое опьянение
- Быстрое восстановление здоровья

## Система опьянения

### Уровни опьянения

1. **Трезв** (0-10%)
   - Никаких эффектов

2. **Слегка пьян** (10-30%)
   - Небольшое размытие экрана
   - Замедление движения мыши

3. **Пьян** (30-60%)
   - Сильное размытие
   - Случайные шатания
   - Замедление реакции

4. **Очень пьян** (60-90%)
   - Экран сильно трясёт
   - Персонаж шатается
   - Случайные падения
   - Тошнота

5. **Мертвецки пьян** (90-100%)
   - Чёрно-белый экран
   - Почти невозможно ходить
   - Эффект слепоты
   - Риск потери сознания

### Как протрезветь

- **Время** — опьянение проходит со временем
- **Молоко** — мгновенно снимает все эффекты опьянения
- **Хлеб** — немного ускоряет отрезвление
- **Кофе** — значительно ускоряет (если есть на сервере)

## Качество напитка

### Факторы качества

Качество напитка зависит от:

1. **Точность рецепта**
   - Правильное количество ингредиентов
   - Правильное время варки

2. **Дистилляция**
   - Нужное количество перегонок

3. **Выдержка**
   - Достаточное время
   - Правильный тип бочки

### Звёздочки качества

- ⭐ (1 звезда) — плохое качество
- ⭐⭐ (2 звезды) — нормальное
- ⭐⭐⭐ (3 звезды) — хорошее
- ⭐⭐⭐⭐ (4 звезды) — отличное
- ⭐⭐⭐⭐⭐ (5 звёзд) — идеальное

### Влияние качества

- Лучше вкус (описание)
- Сильнее положительные эффекты
- Слабее негативные эффекты
- Выше цена продажи

## Команды

### Основные команды

- `/brew info` — проверить уровень опьянения
- `/brew help` — список команд плагина
- `/brew unLabel` — скрыть детали описания напитка

::note
Для использования некоторых команд могут потребоваться права администратора
::

## Советы по пивоварению

### Для новичков

1. **Начните с пива** — простой рецепт, короткая выдержка
2. **Стройте несколько бочек** — процесс долгий, нужен запас
3. **Записывайте рецепты** — легко забыть точные пропорции
4. **Не пейте слишком много** — опьянение мешает играть

### Для опытных

1. **Экспериментируйте** — пробуйте новые сочетания
2. **Используйте таймер** — не перевариватывайте напиток
3. **Стройте погреб** — храните бочки в одном месте
4. **Торгуйте** — качественные напитки ценятся

### Частые ошибки

❌ **Переварка** — слишком долгое время варки  
❌ **Неправильная бочка** — не тот тип дерева  
❌ **Мало выдержки** — не хватило времени  
❌ **Плохое соотношение** — неправильное количество ингредиентов

## Хранение и торговля

### Хранение напитков

- Используйте сундуки или шалкеры
- Подписывайте напитки в наковальне
- Храните ценные напитки в защищённом месте
- Старые напитки могут значительно вырасти в цене

### Создание бара/таверны

Идеи для оформления:

- Постройте барную стойку
- Разместите бочки на стенах
- Добавьте столы и стулья
- Используйте котлы как декор
- Повесьте таблички с меню

## Безопасность

::callout{type="warning"}
**Предупреждение:**
- Не употребляйте алкоголь перед важными задачами
- Опьянение может привести к смерти персонажа
- Абсент и водка очень опасны в больших количествах
::

## Решение проблем

### Напиток не варится

**Проблема:** Время варки не идёт

**Решение:**
- Проверьте, что под котлом есть огонь
- Убедитесь, что в котле есть вода
- Ингредиенты добавлены правильно

### Низкое качество

**Проблема:** Напиток получается 1-2 звезды

**Решение:**
- Проверьте точность рецепта
- Убедитесь в правильном времени варки
- Проверьте количество дистилляций
- Выдержите достаточное время

### Бочка не работает

**Проблема:** Не удаётся положить напиток в бочку

**Решение:**
- Проверьте правильность конструкции
- Убедитесь, что таблички на своих местах
- Проверьте тип древесины
- Пересоздайте бочку
