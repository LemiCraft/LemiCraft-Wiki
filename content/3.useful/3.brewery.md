# Что такое Brewery?

Brewery — это плагин, который позволяет игрокам создавать алкогольные напитки с реалистичной системой опьянения и различными эффектами

### Основные возможности

- Варка различных напитков (пиво, вино, ром, абсент, кофе и др.)
- Система опьянения с визуальными эффектами
- Выдержка напитков для улучшения качества
- Уникальные эффекты для каждого напитка
- Безалкогольные напитки с полезными свойствами

## Процесс создания напитка

Создание напитка состоит из нескольких этапов:

### 1. Варка

**Как варить:**

1. Поставьте котёл над источником огня (лучше всего незерак + огонь)
2. Наполните котёл водой (ПКМ с ведром воды)
3. Добавьте ингредиенты (ПКМ по котлу с предметом в руке)
4. Варите нужное время
5. Наберите напиток в бутылки (ПКМ по котлу с пустыми бутылками)

![Котёл для варки](/images/brewery/cauldron.png)
*Котёл с водой, установленный над источником огня*

::note
**Важно:** Часы показывают, сколько минут варится содержимое котла. Следите за временем варки! В течение первых двух минут вы будете получать сообщение "Котёл только начал кипеть"
::

### 2. Дистилляция

**Что нужно:**
- Варочная стойка
- Светопыль в качестве фильтра

**Как дистиллировать:**

1. Поместите напиток в варочную стойку
2. Добавьте светопыль в верхний слот
3. Дождитесь завершения процесса
4. Повторите нужное количество раз

::note
Не все напитки требуют дистилляции. Проверяйте рецепт!
::

### 3. Выдержка

**Как построить бочку:**

**Маленькая бочка (9 слотов):**

![Маленькая бочка](/images/brewery/small_barrel.png)

Требуется:
- 8 деревянных ступеней
- 1 табличка с текстом "Бочка"

Постройка:
1. Разместите 4 ступени в форме квадрата
2. Поставьте на них ещё 4 ступени
3. На одну из сторон нижнего ряда прикрепите табличку
4. Напишите на табличке "Бочка"
5. В чате появится сообщение "Бочка создана"

**Большая бочка (27 слотов):**

![Большая бочка](/images/brewery/big_barrel.png)

Требуется:
- 16 деревянных ступеней
- 18 деревянных досок
- 5 деревянных заборов
- 1 табличка с текстом "Бочка"

Постройка:
1. Поставьте 4 забора по углам будущей бочки
2. На них сделайте платформу 4×3, по бокам должны быть ступеньки
3. Разместите доски по периметру, чтобы внутри бочка осталась полая
4. Сделайте верхнюю часть бочки - также по бокам ступеньки, а в центре доски
5. Поставьте забор на переднюю часть в качестве краника
6. Прикрепите табличку и напишите "Бочка"
7. В чате появится сообщение "Бочка создана"

**Как выдерживать:**

1. ПКМ по табличке бочки с бутылкой в руке
2. Положите напиток в бочку
3. Подождите нужное время
4. Заберите выдержанный напиток

::note
Для взаимодействия с бочкой используйте **табличку**, а не сами ступени
::

## Система опьянения

### Уровни опьянения

1. **Трезв** (0-10%) — никаких эффектов
2. **Слегка пьян** (10-30%) — небольшое размытие экрана
3. **Пьян** (30-60%) — сильное размытие, случайные шатания
4. **Очень пьян** (60-90%) — экран трясёт, персонаж шатается, тошнота
5. **Мертвецки пьян** (90-100%) — чёрно-белый экран, почти невозможно ходить

### Как протрезветь

- **Хлеб** — снимает 4 ml опьянения
- **Ведро молока** — снимает 2 ml опьянения
- **Золотое яблоко** — снимает 10 ml
- **Зачарованное золотое яблоко** — снимает 100 ml
- **Кофе** — снимает 6 ml и даёт эффекты скорости
- **Холодный кофе** — снимает 8 ml
- **Время** — опьянение проходит само

## Качество напитка

### Факторы качества

1. Правильное количество ингредиентов
2. Точное время варки
3. Нужное количество перегонок
4. Достаточная выдержка в правильной бочке

### Звёздочки качества

- ⭐ — плохое
- ⭐⭐ — нормальное
- ⭐⭐⭐ — хорошее
- ⭐⭐⭐⭐ — отличное
- ⭐⭐⭐⭐⭐ — идеальное

## Команды

- `/brew info` — проверить уровень опьянения
- `/brew help` — список команд плагина
- `/brew unLabel` — скрыть детали описания напитка

## Хранение и торговля

### Стол закупоривания

Закупоривание скрывает информацию о качестве и производителе. Идеально для продажи

**Крафт стола:**

![Крафт стола закупоривания](/images/brewery/sealing-table.png)
*Рецепт создания стола закупоривания*

Ингредиенты:
- 4x Доски (любые)
- 1x Бутылка

Расположение в верстаке:
```
[Б][Б]
[Д][Д]
[Д][Д]
```

**Как использовать:**

1. Поставьте стол закупоривания в мире
2. ПКМ по столу с напитком в руке
3. Напиток будет автоматически закупорен

**Особенности:**
- Нельзя выдерживать дальше
- Нельзя откупорить обратно

::warning
Закупоривание необратимо! Убедитесь, что напиток полностью готов перед закупориванием
::

### Частые ошибки

❌ **Переварка** — слишком долгое время варки  
❌ **Неправильная бочка** — не тот тип дерева  
❌ **Мало выдержки** — не хватило времени  
❌ **Неверное количество ингредиентов**

::note
Помните: умеренность — ключ к успеху! Варите с умом и наслаждайтесь процессом 🍺
::
