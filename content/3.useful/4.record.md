# Как записать пластинку

На сервере LemiCraft вы можете создавать собственные музыкальные пластинки с любой музыкой!

## Что нужно для записи

### Необходимые предметы

1. **Пустая пластинка** — создаётся из обычной пластинки
2. **Проигрыватель** — для воспроизведения
3. **Ссылка на музыку** — URL на аудиофайл

### Поддерживаемые источники

Можно использовать ссылки с:

- **YouTube** — любое видео с музыкой
- **SoundCloud** — треки и плейлисты
- **Прямые ссылки** — `.mp3`, `.wav`, `.ogg` файлы
- **Другие стриминговые сервисы** — проверьте совместимость

::info
**Совет:** YouTube — самый простой и надёжный источник музыки
::

## Процесс записи

### Шаг 1: Получите пустую пластинку

**Способ 1: Очистка пластинки**

Если у вас есть обычная пластинка, её можно очистить:

1. Возьмите любую музыкальную пластинку
2. Используйте команду очистки (если доступна)
3. Получите пустую пластинку

**Способ 2: Покупка/крафт**

- Купите у других игроков
- Получите в награду
- Проверьте возможность крафта (зависит от настроек сервера)

::note
Уточните у администрации актуальный способ получения пустых пластинок на LemiCraft
::

### Шаг 2: Подготовьте ссылку на музыку

**Для YouTube:**

1. Найдите нужную песню на YouTube
2. Скопируйте ссылку из адресной строки
   - Пример: `https://www.youtube.com/watch?v=dQw4w9WgXcQ`
   - Или короткая: `https://youtu.be/dQw4w9WgXcQ`

**Для SoundCloud:**

1. Откройте трек на SoundCloud
2. Нажмите "Share" → "Copy Link"
3. Скопируйте ссылку

**Для прямых файлов:**

1. Загрузите файл на файлообменник
2. Получите прямую ссылку на файл
3. Убедитесь, что ссылка заканчивается на `.mp3`, `.wav` или `.ogg`

::warning
**Важно:** Ссылка должна быть доступна публично, без авторизации
::

### Шаг 3: Запишите пластинку

1. **Возьмите пустую пластинку** в руку

2. **Используйте команду записи:**
   ```
   /record <ссылка>
   ```
   
   Пример:
   ```
   /record https://www.youtube.com/watch?v=dQw4w9WgXcQ
   ```

3. **Дождитесь подтверждения**
   - Сервер обработает ссылку
   - Пластинка будет записана
   - Вы получите сообщение об успехе

::note
Точная команда может отличаться — уточните у администрации или в `/help`
::

### Шаг 4: Назовите пластинку (опционально)

Вы можете дать пластинке красивое название:

1. Положите пластинку и наковальню
2. Переименуйте в наковальне
3. Название будет отображаться при воспроизведении

**Примеры названий:**
- "Never Gonna Give You Up"
- "Мой любимый трек"
- "Музыка для шахты"

## Использование пластинки

### Воспроизведение

1. **Создайте проигрыватель** (Jukebox)
   - Крафт: 8 досок + 1 алмаз

2. **Поставьте проигрыватель** в нужном месте

3. **Вставьте пластинку**
   - ПКМ по проигрывателю с пластинкой в руке

4. **Музыка начнёт играть!**
   - Радиус слышимости: около 64 блоков
   - Громкость зависит от расстояния

### Остановка воспроизведения

- **ПКМ по проигрывателю** — остановить и забрать пластинку
- **Сломать проигрыватель** — пластинка выпадет

## Создание музыкальной комнаты

### Идеи для оформления

**Концертный зал:**
- Разместите несколько проигрывателей
- Постройте сцену
- Добавьте места для зрителей
- Используйте ноты (декор)

**Личная студия:**
- Коллекция пластинок в рамках
- Полки из плит для хранения
- Уютная комната отдыха
- Проигрыватель в центре

**Дискотека:**
- Цветное освещение (стекло + светильники)
- Танцпол из разноцветных блоков
- Несколько проигрывателей
- Барная зона

## Рекомендации по записи

### Выбор музыки

✅ **Подходит:**
- Любимые песни
- Фоновая музыка для фермы/шахты
- Музыка для атмосферы постройки
- Треки для вечеринок

❌ **Избегайте:**
- Слишком громкие/агрессивные треки (могут мешать)
- Музыка с длинными интро (скучно для других)
- Файлы плохого качества

### Качество звука

- Предпочитайте высокое качество (192+ kbps)
- Проверяйте, что трек воспроизводится нормально
- Слишком большие файлы могут не загрузиться

### Организация коллекции

**Система хранения:**

1. **Создайте сундук** для пластинок
2. **Подпишите таблички** с категориями:
   - "Рок"
   - "Электроника"
   - "Классика"
   - "Саундтреки"

3. **Используйте рамки** для красивого отображения

**Каталогизация:**

Ведите книгу с записями:
```
1. Rick Astley - Never Gonna Give You Up
2. C418 - Sweden
3. ...
```

## Совместное прослушивание

### Правила хорошего тона

✅ **Делайте:**
- Спрашивайте соседей, не мешает ли музыка
- Выключайте проигрыватель, когда уходите
- Делитесь интересными находками

❌ **Не делайте:**
- Не ставьте музыку на максимальную громкость рядом с чужими базами
- Не включайте оскорбительный контент
- Не спамьте одним треком

### Музыкальные события

Идеи для ивентов:

- **Концерт** — покажите свои любимые треки
- **Дискотека** — пригласите друзей потанцевать
- **Музыкальная викторина** — угадайте песню
- **Батл DJ** — кто соберёт лучший плейлист

## Решение проблем

### Пластинка не записывается

**Проблема:** Команда не работает

**Решение:**
- Проверьте, что пластинка пустая
- Убедитесь, что ссылка корректная
- Попробуйте другой источник
- Обратитесь к администрации

### Музыка не воспроизводится

**Проблема:** Вставили пластинку, но тишина

**Решение:**
- Проверьте громкость в настройках Minecraft
- Убедитесь, что пластинка записана правильно
- Попробуйте другой проигрыватель
- Перезайдите на сервер

### Плохое качество звука

**Проблема:** Музыка звучит плохо, с помехами

**Решение:**
- Используйте ссылку на версию лучшего качества
- Проверьте стабильность интернет-соединения
- Попробуйте другой источник музыки

### Ссылка не принимается

**Проблема:** Сервер не принимает вашу ссылку

**Решение:**
- Убедитесь, что источник поддерживается
- Попробуйте сократить ссылку
- Используйте YouTube вместо других платформ
- Проверьте, что ссылка публичная

## Полезные команды

Основные команды для работы с пластинками:

```
/record <ссылка> — записать пластинку
/record info — информация о пластинке в руке
/record clear — очистить пластинку
/record help — справка по командам
```

::note
Точный список команд уточняйте у администрации сервера
::

## Авторские права

::callout{type="warning"}
**Важно:**
- Используйте только легальные источники музыки

- Уважайте авторские права композиторов
- На сервере могут действовать дополнительные правила
::
