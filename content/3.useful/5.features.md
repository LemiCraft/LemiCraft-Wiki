# Фишки сервера LemiCraft

LemiCraft предлагает множество уникальных возможностей и улучшений, которые делают игру интереснее и удобнее

## Голосовой чат

На сервере установлен плагин **Plasmo Voice**, который добавляет пространственный голосовой чат

### Основные возможности

- **Пространственный звук** — голос слышен на определённом расстоянии
- **Голосовые сообщения** — можно записывать и отправлять аудио
- **Группы** — создавайте приватные голосовые каналы

### Команды голосового чата

```
/vm — записать голосовое сообщение
/vrc — переподключиться к голосовому чату
```

### Настройка

Для использования голосового чата нужен мод **Plasmo Voice**:
- Скачайте с [Modrinth](https://modrinth.com/plugin/plasmo-voice)
- Поместите в папку `mods`
- Настройте микрофон в игре (клавиша **V**)

::info
Подробнее о настройке Plasmo Voice в разделе [Первый запуск и настройка](/home/start#plasmo-voice)
::

## Действия и эмоции

### Базовые действия

Команды для физических действий персонажа:

```
/sit — сесть на месте
/lay — лечь
/crawl — ползать
/spin — крутиться на месте
/bellyflop — лечь на живот
/sit toggle — вкл/выкл сидение на блоках (через ПКМ)
/sit playertoggle — вкл/выкл возможность сесть на кого-то
```

**Использование:**
- Просто введите команду в чат
- Для отмены: начните движение или прыгните

### RP команды

Команды для ролевой игры:

```
/do <текст> — описательное сообщение (рп)
/me <действие> — совершить действие (рп)
/gme <действие> — действие в глобальном чате (рп)
/try <действие> — попытаться что-то сделать (рп)
/roll [число] — случайное число (по умолчанию до 100, максимум 1000000000)
```

**Примеры:**

```
/me махнул рукой соседу
→ *Игрок_123 махнул рукой соседу*

/do Ярко светит солнце, на улице тепло
→ [Описание] Ярко светит солнце, на улице тепло

/try открыть закрытую дверь
→ Игрок_123 пытается открыть закрытую дверь [Успех/Провал]

/roll 100
→ Игрок_123 бросил кости: 67
```

::note
RP команды помогают создавать атмосферу и улучшают взаимодействие между игроками
::

## Веб-карта сервера

На сервере работает интерактивная **BlueMap** — динамическая 3D карта мира!

### Как открыть карту

**Адрес:** [lemicraft.ru/map](https://lemicraft.ru/map)

### Возможности карты

- Интерактивная 3D карта всех измерений
- Приближение и вращение карты
- Переключение между мирами (Обычный мир, Нижний мир, Край)
- Видны все игроки онлайн в реальном времени

### Маркеры на карте

Вы можете размещать **собственные метки** на карте с помощью баннеров!

**Как создать маркер:**

1. Скрафтите баннер любого цвета
2. Переименуйте его в наковальне — это станет названием метки
3. Установите баннер в нужном месте — метка появится на карте автоматически

::note
Обычные баннеры без названия на карте не отображаются
::

### Приватность на карте

```
/bmpc — скрыть/показать себя на карте
/lb toggle — скрыть/показать себя в локаторе
```

::warning
Ваши **постройки** и **баннеры-маркеры** останутся видимыми на карте, даже если вы скроете себя
::

## Система алкоголя (Brewery)

На сервере работает плагин **Brewery** для варки алкогольных напитков

```
/brew info — проверить уровень опьянения
/brew unLabel — скрыть некоторые детали описания напитка
```

::note
Подробный гайд по варке напитков смотрите в разделе [Brewery](/useful/brewery)
::

## Прочие команды

```
/exp get <опыт> — засунуть опыт в бутылку
/exp get <уровни>L — засунуть уровни опыта в бутылку
/itemlore add <текст> — добавить описание предмету
/treefeller toggle — быстрая рубка деревьев
/axgrave list — список ваших могил
/help — список всех команд
```

## Игровые улучшения

### Достижения

- Строительство
- Исследования
- Сражения
- Добыча ресурсов
- Социальные активности
- Секретные достижения

### Обработка дерева в камнерезе

Теперь можно обрабатывать древесину в камнерезе:
- Брёвна → доски (более эффективно)
- Доски → ступени, плиты, забор

### Привлечение жителей

Возьмите изумруд или изумрудный блок в руку — житель будет следовать за вами

### Окисление меди

Используйте густое взрывное зелье на медный блок для мгновенного окисления

### Связать игроков поводком

Игроков можно связать поводком — полезно для RP и совместных путешествий

## Кастомные блоки и предметы

### Текст на шалкерах

Переименуйте шалкер в наковальне — название появится над блоком

### Система могил

После смерти на вашем месте появляется могила. В ней сохраняются все вещи и опыт

```
/axgrave list — список ваших могил
```

### Головы мобов

При убийстве моба есть шанс получить его голову. Используйте как декор или коллекционируйте
