# Фишки сервера LemiCraft

LemiCraft предлагает множество уникальных возможностей и улучшений, которые делают игру интереснее и удобнее

## Голосовой чат

На сервере установлен плагин **Plasmo Voice**, который добавляет пространственный голосовой чат

### Основные возможности

- **Пространственный звук** — голос слышен на определённом расстоянии
- **Голосовые сообщения** — можно записывать и отправлять аудио
- **Группы** — создавайте приватные голосовые каналы

### Команды голосового чата

```
/vm — записать голосовое сообщение
/vrc — переподключиться к голосовому чату
/bmpc — скрыть/показать себя на веб-карте
```

### Настройка

Для использования голосового чата нужен мод **Plasmo Voice**:
- Скачайте с [Modrinth](https://modrinth.com/plugin/plasmo-voice)
- Поместите в папку `mods`
- Настройте микрофон в игре (клавиша **V**)

::info
Подробнее о настройке Plasmo Voice в разделе [Первый запуск и настройка](/home/start#plasmo-voice)
::

## Действия и эмоции

### Базовые действия

Команды для физических действий персонажа:

```
/sit — сесть на месте
/lay — лечь
/crawl — ползать
/spin — крутиться на месте
/bellyflop — лечь на живот
```

**Использование:**
- Просто введите команду в чат
- Для отмены: начните движение или прыгните

**Примеры использования:**
- Сидеть на ступеньках или плитах
- Лежать на кровати/диване
- Ползать в узких проходах для красоты

### RP команды

Команды для ролевой игры:

```
/do <текст> — описательное сообщение (рп)
/me <действие> — совершить действие (рп)
/gme <действие> — действие в глобальном чате (рп)
/try <действие> — попытаться что-то сделать (рп)
/roll [число] — случайное число (по умолчанию до 100, максимум 1000000000)
```

**Примеры:**

```
/me махнул рукой соседу
→ *Игрок_123 махнул рукой соседу*

/do Ярко светит солнце, на улице тепло
→ [Описание] Ярко светит солнце, на улице тепло

/try открыть закрытую дверь
→ Игрок_123 пытается открыть закрытую дверь [Успех/Провал]

/roll 100
→ Игрок_123 бросил кости: 67
```

::note
RP команды помогают создавать атмосферу и улучшают взаимодействие между игроками
::

## Игровые улучшения

### Достижения

На сервере доступно **более 1000 кастомных достижений**:

- Строительство
- Исследования
- Сражения
- Добыча ресурсов
- Социальные активности
- Секретные достижения

**Как посмотреть:**
- Откройте меню достижений (клавиша **L**)
- Изучите доступные категории
- Отслеживайте прогресс

### Обработка дерева в камнерезе

Теперь можно обрабатывать древесину в камнерезе!

**Доступные рецепты:**
- Брёвна → доски (более эффективно)
- Доски → ступени
- Доски → плиты
- Доски → забор

**Преимущества:**
- Экономия ресурсов
- Быстрое создание декоративных блоков
- Удобство в больших стройках

### Привлечение жителей

Жителей теперь можно привлекать изумрудами!

**Как это работает:**
1. Возьмите изумруд или изумрудный блок в руку
2. Подойдите к жителю
3. Житель будет следовать за вами

**Применение:**
- Переселение жителей
- Создание торговых залов
- Заселение деревень

### Окисление меди

Можно ускорить окисление медных блоков!

**Как использовать:**
1. Создайте густое взрывное зелье
2. Используйте на медный блок
3. Медь мгновенно окислится

**Стадии окисления:**
- Обычная медь → Слегка окисленная
- Слегка окисленная → Окисленная
- Окисленная → Сильно окисленная

## Кастомные блоки и предметы

### Текст на шалкерах

Кастомные шалкеры могут иметь текст над собой!

**Особенности:**
- Название отображается при взгляде
- Помогает организовать хранилище
- Красиво смотрится

**Как создать:**
- Переименуйте шалкер в наковальне
- Название появится над блоком

### Система могил

После смерти на вашем месте появляется могила

**Как это работает:**
1. При смерти создаётся могила
2. В могиле сохраняются:
   - Все ваши вещи
   - Весь опыт
3. Чтобы забрать — сломайте могилу

**Преимущества:**
- Вещи не разбрасываются
- Защита от деспавна предметов
- Легко найти место смерти
- Опыт не пропадает

::callout{type="success"}
Могилы защищены от других игроков в течение определённого времени
::

### Головы мобов

При убийстве моба есть шанс получить его голову!

**Применение:**

- Коллекционирование

- Украшение баз

**Популярные головы:**
- Крипер
- Скелет
- Зомби
- Эндермен
- И другие мобы

### Кастомные рамки

На сервере доступны улучшенные рамки!

**Возможности:**
- Невидимые рамки

**Как получить:**

### Стойки для инструментов

Специальные стойки для демонстрации инструментов и оружия

**Применение:**
- Оружейная
- Музей

## Специальные блоки

### Блок света

Можно создать невидимый источник света!

**Крафт:**
- Рецепт уточняйте у администрации
- Или используйте специальную команду

**Как сломать:**
1. Возьмите блок света во вторую руку
2. Зажмите **Shift**
3. Сломайте блок

**Применение:**
- Скрытое освещение
- Подсветка построек
- Декоративное освещение без факелов

### Предметы в подвесных табличках

Красивый способ демонстрации предметов!

**Как создать:**

1. Поставьте подвесную табличку
2. Зажмите **Shift**
3. Поставьте рамку на табличку
4. Поместите предмет в рамку

**Результат:**
- Предмет "висит" на табличке
- Выглядит очень эстетично
- Отлично для витрин и музеев

### Улучшенные котлы

Котлы имеют расширенный функционал!

**Возможности:**
- Хранение различных жидкостей
- Смешивание зелий
- Использование в Brewery
- Декоративные применения

## Веб-карта сервера

На сервере есть интерактивная карта мира!

**Адрес:** `lemicraft.ru/map`

**Возможности:**
- Просмотр всего мира
- Поиск баз
- Отслеживание игроков
- Просмотр координат

**Команда:**
```
/bmpc — скрыть/показать себя на карте
```

::warning
Используйте `/bmpc` если не хотите, чтобы другие видели ваше расположение
::
